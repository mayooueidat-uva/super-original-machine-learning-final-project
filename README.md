# Bank Marketing ML Project

A machine learning project to predict term-deposit subscription outcomes for bank clients, using multiple models and comprehensive evaluation.

## Software and Platform Requirements

- **Python 3.8+**
- **Jupyter Notebooks**
- **Packages:**
  - pandas
  - numpy
  - scikit-learn
  - matplotlib
  - seaborn
  - PyTorch
- **Operating System:** Mac, Windows, or Linux
